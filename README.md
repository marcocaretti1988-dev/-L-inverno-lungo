# ЗИМА · Cold Cycle

Gioco isometrico invernale in Three.js, in un unico file (`index.html`).

ЗАТО-42, 12 febbraio 1991. Dmitri «Volk» Voronin si risveglia in una città sovietica sepolta dalla neve.
La neve ricorda tutto. Ogni passo resta. E qualcosa, nella nebbia, segue i tuoi.

## Capitoli
- I · Il Cortile
- II · La fermata del filobus
- III · Il posto di blocco

## Giocare
Apri la pagina di GitHub Pages del repository. Su iPhone: Safari → Condividi → «Aggiungi alla schermata Home»
per averlo a schermo intero con la sua icona.

Comandi: WASD / frecce per muoversi, SHIFT corri, E / SPAZIO esamina, T torcia, H aiuto, Z / X ruota la camera, rotella zoom, I zaino.
Su telefono: joystick a sinistra, pulsanti a destra.
